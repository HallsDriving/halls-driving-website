HOW TO REVIEW
Open index.html in a web browser. Use the menu to review every page.

HOW TO ADD A STUDENT PHOTO
1. Put the new photo in the assets folder.
2. Open student-success.html in a text editor.
3. In the div with class="gallery", copy one complete <figure>...</figure> block.
4. Change the image filename in src="assets/your-photo.jpg".
5. Update the alt text and caption, then save.
6. Only publish photos with student and/or parent/legal guardian permission.

HOW TO UPDATE THE CALENDAR
- Open defensive-driving.html in a text editor.
- Each month is inside a block with class="month-panel".
- Keep data-year and data-month accurate (January=1 through December=12).
- Add class="available" to a date box to highlight it.
- site.js automatically hides a month only after that month has ended.
